# Team setup

1. Have one teammate [set up Agentorch in your project repository](../README.md#open-your-first-draft-pr).
2. Have each teammate install Agentorch, sign in to GitHub, and check the board
   from inside the project checkout with `agentorch board whoami`.
3. Give each agent its own signature and cursor. Ask it to check
   `agentorch board unread` and follow the project's instructions.
4. Hand off a small task, open a draft PR, and check the board for the link.

If your team uses another ticket system, follow the
[tracker setup guide](TRACKERS.md). For a team already using a Linear issue as
its board and the Linear planner commands, see the
[Linear board setup](../SETUP.md#6-linear-mode-a-mega-doc-tickets-and-server-sub-agents).
